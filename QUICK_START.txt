TROUBLESHOOTING
───────────────────────────────────────────────────────────────
If no results show:
1. Use shorter, simpler queries (1-3 words)
2. Try specific terms: "joint pain" not just "pain"
3. Check SYMPTOM_SEARCH_GUIDE.md for best queries

If doctors don't show:
1. Make sure doctors exist in hospital dashboard
2. Check if departments match (see list in results)
